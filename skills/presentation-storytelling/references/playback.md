# 演示播放验收

当用户需要配音、动效、逐步揭示或离线预览时使用。交付形式可以是可编辑幻灯片、HTML 预览或其他适合现场的格式。

- **讲稿先定稿。** 生成前保存当前讲稿快照。音频逐段对应原文和揭示步骤。改稿后只重做受影响的段，防止插页后音频串页。用户明确要试听时，可以先做一小段并标明是样音。
- **把播放留在演示里。** 有独立讲稿面板时，可以把小型播放／暂停按钮和倍速合到标题栏。从当前页或当前段开始读，续读时推进对应画面。手动跳页、暂停后继续、调倍速和最后一段结束，都要试一次。
- **根据素材用途决定播放。** 用于对照或氛围的短动效可以入页后静音循环，翻页时暂停。需要听原声或细看操作时，保留独立播放控制。要求离线时，将所需媒体随演示稿交付，先显示有效封面或首帧。
- **验证可见画面。** 文件存在、解码通过、音频进度变化都不能单独证明观众能看到。用实际展示软件或浏览器打开，分别检查直接打开该页、从前页进入、配音自动推进、离页后返回。若有线上评审，也在上传后的版本复查。
- **黑屏时找出故障层。** 依次检查源文件、嵌入地址、实际播放状态和可见画面。对短、静音、只需循环的动效，兼容的动画图片可以作为后备，需实际确认它能动、清晰且大小合适。对有原声、需要拖动进度或较长的素材，优先保留视频并处理兼容性。
- **导出与分享。** 本地版有离线要求时，断网再检查一次。上传后的评审版可能会重新托管媒体，确认分享链接打开的是这次提交的版本，以及图片、动效和讲稿音频都可用。
