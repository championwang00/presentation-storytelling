# 换主题示例：社区图书馆

图书馆要在 8 分钟内推荐一个社区学习项目的视觉方向，已经有几张参考稿。旧方案一个活泼但不容易被记住，另一个让常客有归属感，但新来的人可能以为只对会员开放。交付要可编辑。讲稿仍在改，配音预览可以在定稿后补。

| 演示段落 | 画面 | 讲述重点 |
| --- | --- | --- |
| 看看试过什么 | 各用一句话和一张现有参考介绍两案 | 第一案容易接近，第二案有归属感，各有需要解决的问题 |
| 把顾虑合成问题 | 一句话「怎样让人认得出这个项目，也敢第一次走进来？」 | 解释视觉辨识度与新人能否看懂如何参加，都是新方向要检验的事 |
| 介绍新方向 | 「邻里学习桌」和一张最能表达它的现有参考 | 先看图，再指出桌面构图和清楚的活动入口如何让邀约更具体 |
| 放到不同活动里试 | 成人课程、儿童工作坊、地方史三张对照稿 | 共用标题位置和活动信息结构，各活动用不同主题图。请观众试着认出活动、适合谁以及怎么参加 |
| 明确下一步 | 一句话「先在三类活动中试用」 | 用相同问题向新来的人和常客验证，再决定是否推广 |

过渡页的讲稿示例：

> 第一个方案让活动显得好接近，但放到其他海报旁边，可能认不出是我们。第二个方案让常来的人有熟悉感，可第一次来的人也许会想，我能参加吗？所以我想试一个新方向，让图书馆保留自己的辨识度，也让第一次来的人一眼看懂怎么加入。

做成可编辑幻灯片时，保留标题、标签、对照结构和讲稿的编辑能力。若某个应用还缺图，先标为待验证。配音等讲稿批准后再生成。
