# 视觉提案与演示讲述

一个可复用的 Agent Skill，适合整理 PPT、视觉方向提案和设计汇报。它把方向比较、参考解读、实际应用和演示讲稿组织成观众能跟上的论证，适用于 PowerPoint、在线幻灯片或 HTML 演示。

[查看 Skill](skills/presentation-storytelling/SKILL.md) · [社区图书馆示例](skills/presentation-storytelling/references/library-example.md)

在 Codex 中，可以用 `$skill-installer` 安装仓库里的 `skills/presentation-storytelling`，然后用 `$presentation-storytelling` 调用。例如：

> 用 $presentation-storytelling，把这三套方向和已有参考整理成一份 8 分钟的可编辑提案，附上逐页讲稿。配音等我定稿后再做。
